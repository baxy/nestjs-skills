# Analysis Checklist

Complete before writing any specifications.

- [ ] Entry points identified and read
- [ ] Core modules / packages inventoried
- [ ] Configuration files examined
- [ ] Data models / entities located
- [ ] Primary request / user flows traced
- [ ] Authentication and authorization patterns noted
- [ ] Error handling patterns observed
- [ ] External integrations listed
- [ ] Technical debt markers (TODO/FIXME/HACK) collected
- [ ] Validation checkpoint passed (sufficient coverage)
- [ ] Facts vs. inferences distinguished
- [ ] Uncertainties listed for the user
