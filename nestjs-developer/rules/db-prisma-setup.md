## PrismaService as Injectable Singleton with Lifecycle

Create a single `PrismaService` that implements NestJS lifecycle hooks and is provided by a global module. Never create new client instances inside services.

### Prisma 6 (class extends PrismaClient)

```typescript
// src/prisma/prisma.service.ts
import { Injectable, OnModuleInit, OnModuleDestroy } from '@nestjs/common';
import { PrismaClient } from '@prisma/client';

@Injectable()
export class PrismaService extends PrismaClient implements OnModuleInit, OnModuleDestroy {
  async onModuleInit() {
    await this.$connect();
  }

  async onModuleDestroy() {
    await this.$disconnect();
  }
}
```

### Prisma 7+ (driver adapter + generated client)

In Prisma 7 the client is generated as TypeScript files (often under `src/generated/prisma`). You still extend the generated `PrismaClient`, but you must pass a driver adapter:

```typescript
import { Injectable, OnModuleInit, OnModuleDestroy } from '@nestjs/common';
import { PrismaClient } from '../generated/prisma/client';
import { PrismaPg } from '@prisma/adapter-pg';

@Injectable()
export class PrismaService extends PrismaClient implements OnModuleInit, OnModuleDestroy {
  constructor() {
    const adapter = new PrismaPg({
      connectionString: process.env.DATABASE_URL,
    });
    super({ adapter });
  }

  async onModuleInit() {
    await this.$connect();
  }

  async onModuleDestroy() {
    await this.$disconnect();
  }
}
```

### Prisma 8

Prisma 8 removes the class. The client is a plain object created in a module (e.g. `src/prisma/db.ts`). `PrismaService` then becomes a thin injectable that holds that client and still implements the lifecycle hooks. Check the official NestJS template generated by `create-prisma` for the exact shape.

### Global module

```typescript
// src/prisma/prisma.module.ts
import { Global, Module } from '@nestjs/common';
import { PrismaService } from './prisma.service';

@Global()
@Module({
  providers: [PrismaService],
  exports: [PrismaService],
})
export class PrismaModule {}
```

Import `PrismaModule` once in `AppModule`.

### Testing

In unit tests, provide a mock instead of the real service:

```typescript
const mockPrisma = {
  user: {
    findMany: jest.fn(),
    create: jest.fn(),
  },
};

const module = await Test.createTestingModule({
  providers: [
    UsersService,
    { provide: PrismaService, useValue: mockPrisma },
  ],
}).compile();
```
